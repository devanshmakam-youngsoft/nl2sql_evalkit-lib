An assistant that is already deployed

No access to its code? Your function can simply call it over HTTP, and nl2sql_evalkit scores whatever comes back. This version uses only the standard library and passes the session id along, so multi-turn test cases keep their memory on the assistant's side.

{{example:call_existing_api.py}}

If the API returns a JSON object with the SQL under a key of its own, return the object as it is and list the key with answer_keys=[…]. The SQL is only read, never run, so it makes no difference whether the real database sits behind that API.

Safe by default

Evaluation never connects to your database, so it cannot change your data. For an extra guarantee, serve(..., eval_env="prod") turns the dashboard and every evaluation route off; only /api/health answers.
