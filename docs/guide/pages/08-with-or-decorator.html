What each one records

Run the question “Total sales per region” through both and this is what the dashboard keeps:

Recorded for the stepwith blockDecorator
Step name and how long it tookyesyes
Inputs of the stepnot recordedevery argument, by name
Output of the stepwhat you assign to s.outputthe return value
Coversany block, even part of a functionthe whole function
Shown, not scored

What a step records appears beside the question, which helps when you read a wrong query. The judge does not read it: it grades the SQL your function returns.

Which one should I use?

Use withFor parts of functionsYou can wrap just a few lines, and decide exactly what to attach to the question.
Use a decoratorWhen a function is one clear stageInputs and output show up in the step details with no extra code, which helps when chasing a wrong query.
Mix freelyOne pipeline can use bothA decorator on the model call, a with block on the table picker. They add up the same way.
